# Corporate Operational Manual Template

A professional operational manual design template built with HTML/CSS.

## Features
- Cover page with corporate branding
- Table of contents with section navigation
- Process workflow diagrams
- KPI infographic pages with bar charts
- Clean modern design system
- Light/dark mode compatible

## Pages Included
1. Cover Page
2. Table of Contents
3. Workflow Process Page
4. KPI & Infographics Page

## Tech
Pure HTML + CSS — no frameworks, no dependencies.
